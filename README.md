## О себе

Инженер с **более чем 6 годами опыта** разработки высоконагруженных web-приложений. Специализируюсь на архитектуре и запуске продуктов полного цикла на **Vue.js, Nuxt.js, TypeScript и Node.js**. Есть практический опыт с React, Next.js, Rust и Tauri.

Совмещаю роли **Technical Lead и ведущего разработчика**: принимаю архитектурные решения, руковожу кросс-функциональной командой, развиваю инженерные процессы, провожу code review и участвую в найме.

С апреля 2026 года — **Senior Fullstack Developer в Алабуга ОЭЗ ППТ**. Отвечаю за техническое развитие frontend-платформы внутренних и публичных продуктов. Ранее как **Founding Engineer** самостоятельно спроектировал и запустил zaborrf.ru — от выбора стека и разработки до инфраструктуры, SEO и дальнейшего развития.

## 🛠 Главный Pet-проект: YTooly

<a href="https://the-site-neon.vercel.app/" target="_blank" rel="noopener noreferrer"><img src="https://img.shields.io/badge/YTooly-the--site--neon.vercel.app-22d3ee?style=for-the-badge&amp;logo=vercel&amp;logoColor=white" alt="YTooly" /></a>

**30+ онлайн-инструментов в едином интерфейсе** — конвертация медиа, онлайн-радио с 3D-визуализацией, маркетплейс с монетизацией, шейдер-редактор, финансовые и dev-инструменты.

> Полный цикл разработки: от FSD-архитектуры до платёжной системы.

| Область | Решение |
| --- | --- |
| Архитектура | Feature-Sliced Design (FSD) · Nuxt 3 SSR+SSG · TypeScript strict |
| Backend | Nitro + PostgreSQL 18 · REST API · WebSocket |
| Монетизация | Stripe (карты) + NowPayments (BTC/ETH/USDT) · HMAC-SHA256/SHA512 |
| 3D / WebGL | Three.js (аудиовизуализация) · GLSL шейдер-редактор с live-preview |
| UX | Drag-and-drop маркетплейс · тёмная тема · glassmorphism · PWA |
| Качество | Vitest · Playwright E2E · ESLint · Prettier · Husky |
